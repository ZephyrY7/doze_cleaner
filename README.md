# Doze Whitelist Cleanup

Module for OPlus/ColorOS devices that removes selected third-party applications from the system DeviceIdle/Doze whitelist.

## Requirements

* Rooted OPlus/ColorOS device
* KernelSU
* A device using the OPlus `my_region` battery configuration

## How it works

It modifies the source whitelist configuration used by OPlus's battery management. Allowing the normal OPlus whitelist generation process to work without continuously running a background service.

OPlus/ColorOS maintains a system whitelist configuration at:
`/my_region/etc/battery/sys_deviceidle_whitelist.xml`

It contains packages exempted from normal DeviceIdle/Doze restrictions.

It's used by Oplus to generate the local Doze whitelist at:
`/data/oplus/os/battery/doze_wl_local.xml`

The local file can be regenerated by the system from various occasions

---

This module provides a modified copy of: `sys_deviceidle_whitelist.xml`
and bind mounts it over the original: `/my_region/etc/battery/sys_deviceidle_whitelist.xml`

Thus, only packages included in the modified `sys_deviceidle_whitelist.xml` will be sourced and added to the local Doze whitelist.
Therefore does not need to repeatedly execute adb commands to remove/add whitelist.

## Verify

After reboot:

```sh
su
dumpsys deviceidle whitelist
```

You can also check the OPlus local whitelist:
`cat /data/oplus/os/battery/doze_wl_local.xml`

## Disclaimer

This module modifies OPlus battery/Doze configuration. Behavior may vary between ColorOS/OPlus versions, devices and regional firmware configs.

Keep a backup of the original configuration before installing.

Use at your own risk.
